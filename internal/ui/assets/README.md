### 自作の画像（DES-UI-22、#80）

両軍の騎兵（自軍のエルザ・敵の cavalier）の、馬に乗った絵（決定（E-41））。Tiny Town・Tiny Dungeon には騎乗の絵がなく、Tiny Dungeon 97（面頬の騎士）の代用は採らない（REV-042 F-01）。

| 素材 | 作者 | 作成日 | 利用許諾 | ファイル |
|---|---|---|---|---|
| 騎兵（16 × 16、1 枚） | レンキン・タクティクスの開発（sakana396。Claude Code が描いた） | 2026-10-23 | 自作。CC0 1.0 として扱う（同梱の Kenney 素材と同じ条件）。ライセンスの原本はない | `original.png` |

- 探した素材（2026-10-23）: Kenney の他のパック（Tiny Battle は CC0・16 × 16 だが、現代の兵器と兵士で馬はない）、OpenGameArt の CC0 素材（zwonky の「Horses - Arne16」<https://opengameart.org/content/horses-arne16> と、それに乗せる騎士の絵は 16 × 16・CC0 だが、Arne16 の 16 色で描かれ、馬だけで 16 × 16 を使い、人物は別の絵を重ねる作り。馬の元の絵は DualR の作で、元の絵の利用許諾はページに書かれていない。配色・描き方が Tiny Dungeon と違い、出どころも一つにならない）。絵柄の合う騎乗の絵が見つからなかったので自作した
- 作り方: Go の `image/png` で書く小さなプログラム（リポジトリには入れていない）で、16 × 16 の文字の表から画素を置いた。色は `tiny_dungeon.png` の中で使われている色だけ（輪郭 #3f2631、馬の茶 #763b36・#bd6c4a・#eaa56c、鋼 #c0cbdc・#8b9bb4・#52607c、肌 #f7c282・#e19a65、目 #262b44）を使い、Tiny Dungeon と同じく太い暗い輪郭で囲んだ
- 絵: 左を向いた茶色の馬に、鋼の兜をかぶった人物が乗る。陣営の色は持たず、自軍・敵とも同じ絵を使い、下地の色（青・赤）で見分ける

## 使ったタイル（DES-UI-05、#12）

タイルの番号は、画像の左上を 0 として右へ数える（1 行に 12 枚。番号 n は x = n % 12、y = n / 12 の位置）。自作の画像（`original.png`）は 1 枚だけで、番号 0 を使う。16 × 16 px を 2 倍で描く。定数は `assets.go` にある。

- 地形は `tactics.Terrain` の名前（平地・森・山・砦・壁）で選ぶ。名前の分からない地形は、通れなければ壁、回復があれば砦、それ以外は平地として描く
- ユニットは、主人公 → 騎兵・錬金術師・魔道士 → そのほかのボス → 陣営と武器の列の先頭の種類、の順で選ぶ（DES-UI-22、DES-CMP-11）。`tactics.Unit` はクラスの ID を持たないため、この 3 兵種はクラスの表示名（`ClassName`）で両軍とも見分ける。兵種のボスも同じ絵にし、ボスの印を重ねる。それ以外のクラスは陣営と武器の列の先頭の種類で選ぶ。自軍と敵は下地の色（青・赤）でも見分ける

## 武器の種類の絵（DES-UI-06、#27）

情報欄の武器の行に、武器の種類の絵を 2 倍（32 px）で添える。剣・槍・斧は Tiny Dungeon、弓は Tiny Town から選んだ（Tiny Dungeon に弓はない）。番号の数え方は上と同じ。情報欄のユニットの絵は、上の表のユニットのタイルを 4 倍（64 px）で描く。

| 用途 | 画像 | 番号 | 絵 |
|---|---|---|---|
| 剣 | Tiny Dungeon | 104 | 銀の長剣 |
| 槍 | Tiny Dungeon | 131 | 柄の長い槍 |
| 斧 | Tiny Dungeon | 119 | 片刃の斧 |
| 弓 | Tiny Town | 118 | 弓 |
| 杖（DES-UI-18、#45） | Tiny Dungeon | 125 | 紫の宝玉の杖 |
| 魔法（DES-CMP-11、#125） | 自作（mages.png） | 2 | 炎 |

### 自作の錬金術師・魔道士・魔法の印（DES-CMP-11、#125）

| 素材 | 作者 | 作成日 | 利用許諾 | ファイル |
|---|---|---|---|---|
| 錬金術師・魔道士・炎の印（各 16 × 16、横に 3 枚） | レンキン・タクティクスの開発（炎の印は Codex、錬金術師・魔道士は Claude Code が画素を描いた） | 2026-11-01 | 自作。CC0 1.0 として扱う | `mages.png` |

- Tiny Dungeon の配色（輪郭 #3f2631、暗色 #262b44、服 #52607c・#8b9bb4、肌 #f7c282・#eaa56c、髪 #bd6c4a、杖の柄と炎 #763b36、薬 #43e1b3・#25956a、瓶の光 #c0cbdc、宝玉 #9b4ca3・#d176d0）で描いた。ネットワークの素材は使っていない
- 初めの版（Codex）は人物が 16 × 16 の上の 13 行だけで同梱の人物より小さく、魔道士が杖を持っていなかった。撮影の確認（2026-11-01）で、同梱の人物（111・112）と同じ大きさに描き直し、魔道士に杖を持たせた
- 番号 0 は瓶を持つ短い服の錬金術師、1 は杖を持つ長い服の魔道士、2 は魔法の武器種を示す炎。陣営の色は付けず、盤面の下地の色で分ける
- `unitTile` はクラス名を主人公の次に調べる。装備を持ち替えても絵は変わらない。魔法の印は `weaponTile` で番号 2 を使う
