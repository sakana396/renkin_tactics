ケース ID は `TC-DES-NG-10-<連番 2 桁>`。表の列は、ID、対象、前提、入力・操作、期待結果、種別の 6 列。期待値は実装の出力を写さず、設計メモの規則と、切り替えを入れる前の定数（1 マス 32 px の配置）から手で決めた。
マスの大きさはパッケージの変数なので、48 に切り替えるテストは `useTestMetrics`（終わったら既定へ戻す）を使い、`t.Parallel` を使わない。既定（32）のままの既存のテストが、そのまま通ることも合格の条件にする（全体の `go test`）。
ebiten を読み込むテストは `xvfb-run -a go test ./...` で動かす。
