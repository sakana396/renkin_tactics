# テスト仕様書（開発の道具）

- 文書 ID: TST-TOOLS
- 版: 0.1
- 対象: `tools/tccheck`（ふしぎ錬金の `tools/tccheck` と、そのテストケース TC-QA-02-01〜04 を引き継いだ）

## 1. 方針

| 項目 | 内容 |
|---|---|
| テストケース ID | `TC-<要求ID>-<連番2桁>` |
| コードとの対応 | 表駆動テストのサブテスト名にテストケース ID を入れる |

## 2. テストケース

### QA-02（テストケース ID の整合）

QA-02 は、ふしぎ錬金の SRS の QA-02（すべての要求をトレーサビリティマトリクスで設計要素とテストケースに対応付ける）を引き継ぐ。SRS を作るときに、このリポジトリの要求として書く。

| ID | 対象 | 前提 | 入力・操作 | 期待結果 | 種別 |
|---|---|---|---|---|---|
| TC-QA-02-01 | tools/tccheck | 範囲表記のトレーサビリティ、結果の表、同じ ID を使う複数のサブテストがある | 検査する | 誤りなし。手動のテストケースだけが警告になる | 正常 |
| TC-QA-02-02 | tools/tccheck | テスト仕様書に同じ ID の定義が 2 行ある | 検査する | 重複を誤りとして報告する | 異常 |
| TC-QA-02-03 | tools/tccheck | テストコードとトレーサビリティに、テスト仕様書にない ID がある | 検査する | それぞれを誤りとして報告する（範囲表記は展開して調べる） | 異常 |
| TC-QA-02-04 | tools/tccheck | テスト仕様書にあってトレーサビリティにない ID がある | 検査する | 誤りとして報告する | 異常 |
