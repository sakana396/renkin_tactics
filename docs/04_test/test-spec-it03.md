# テスト仕様書（反復 3）

- 文書 ID: TST-IT03
- 版: 0.1（骨組み。実装とともに書き足す）
- 対象: [反復 3 計画書](../iterations/it03/plan.md) v0.2 の範囲、[設計書 DES-IT03](../03_design/design-it03.md) v0.2

本書は Issue #60 で作成した枠であり、テストケースはまだ定義していない。各実装 Issue の担当が、設計書 8.2 節の案をもとに前提・入力・期待結果を具体化し、テストコードとトレーサビリティの担当行を同時に更新する。

## 1. 方針

| 項目 | 内容 |
|---|---|
| テストケース ID | `TC-<要求ID>-<連番2桁>`。新規要求は 01 から、既存要求は反復 1・2 の仕様書を照らし、既存の最後の番号の次から振る |
| コードとの対応 | 表駆動テストを基本とし、サブテスト名にテストケース ID を入れる。正常・境界・異常を確かめる |
| 書き足し方 | 各担当が自分の要求の節に行を追加する。同じ要求を複数の Issue が担当するときも同じ節に書き足す |
| 期待値 | 実装の出力を写さず、承認済みの要求と設計から導く |
| 乱数と巻き戻し | PCG の保存・復元は実際の PCG で検証し、固定列の差し替えによる検証と分ける。巻き戻しのない既存の乱数列も保つ |
| 失敗時の状態不変 | 戦闘・Campaign・入力の配列だけでなく、履歴・乱数・敵軍の進行位置・残り回数も確かめる |
| 既存ケースの改訂 | 設計書 8.3 節に従い、ID と既存の規則の確認を保ち、元の反復の仕様書の行を直す |
| 表の取り込み | 変更した要求・ケースの行を照合し、列数・行末の区切り・表の中の空行を確認する（REV-031 F-01、REV-033 F-01・F-02） |

## 2. テストケース

列は「ID、対象（要求・設計）、前提、入力・操作、期待結果、種別」の 6 列とする。具体的なケースの行は各実装 Issue で追加する。

### FR-BTL-10（巻き戻し）

対象は DES-RWD-01〜04、DES-UI-19、設計書 6 章。履歴の深い写し、行動・番の境界、乱数、回数、敵軍の再開、未来の破棄、敗北・勝利からの復帰、入力と表示を確かめる。

### FR-CMP-11（出撃の配置）

対象は DES-DEP-01、DES-UI-20、設計書 6 章。主人公を含む交換・空き枠への移動、不正な配置の拒否、名簿への結果の対応、配置と準備・戦闘の遷移、種を取得する時機を確かめる。

| ID | 対象 | 前提 | 入力・操作 | 期待結果 | 種別 |
|---|---|---|---|---|---|
| TC-FR-CMP-11-01 | FR-CMP-11 / DES-DEP-01 | 名簿順と異なる出撃順 [0,2,1] | 枠 [1,0,2] で主人公と仲間を交換 | 指定した枠の座標に置き、Units と Members は出撃順。Campaign・入力・既存 Sortie を変えず、入力と返す値は独立 | 正常 |
| TC-FR-CMP-11-02 | FR-CMP-11 / DES-DEP-01 | 出撃枠が 3 個 | 主人公のみを枠 0・2、2 人を枠 [2,0]、3 人を枠 [2,0,1] に配置 | 最小・最大の枠、空き枠、枠いっぱいの配置が成功。主人公も最後の枠に置ける | 境界 |
| TC-FR-CMP-11-03 | FR-CMP-11 / DES-DEP-01 | 3 枠の目録、別の既存 Sortie | 空・枠超過・名簿の範囲外・戦死・重複・主人公不在または先頭以外、枠数不一致・負・上限外・重複、クリア済み、組み立てと tactics.New の失敗 | 既存の検証後、枠の長さ・全添字の範囲・重複の順で理由付き ErrInvalidDeployment。クリア済みは ErrCleared が優先。組み立ての誤りは保持。返す Sortie・出来事は nil、Campaign・入力・既存 Sortie は不変 | 異常 |
| TC-FR-CMP-11-04 | FR-CMP-11 / DES-DEP-01、DES-CMP-06 | 出撃順 [0,2,1] と枠 [2,0,1]、主人公の経験 80、仲間は離脱またはロスト | 仲間が倒れた後、主人公が撃破して勝利を反映。配置前後のセーブを比較 | 主人公は Lv 2・経験 10、成長率 100 の 5 能力各＋1。控えと仲間の経験・能力・生死・手持ちは元の名簿に反映し、未出撃者は不変。結果も出撃順。配置はセーブに含まれない | 正常 |

### 既存要求の追加・回帰確認

対象は FR-CMP-03、FR-CMP-09、IF-01・02、NFR-04〜07・09 など、設計書 8.1・8.3 節で対応付けた要求。既存ケースを改訂する場合は元の仕様書を更新し、新しいケースが必要な場合だけ本書に追加する。

## 3. 手動確認

巻き戻しの前後の盤面・行動一覧・回数と、配置の枠・選択・交換・空き枠への移動を Windows で確かめる。REV-033 I-01 の緑の回復範囲・枠・回復量と僧侶・杖の見分けやすさは、設計書 8.2 節と Q-IT03-08 に従い、後続 Issue で既存要求の次の未使用番号を使ってケースを追加する。

Linux の手動確認は反復 3 の範囲外とし、反復 1 の Linux 動作確認ケースは未実施のまま先の反復へ送る（Q-IT03-09、E-37）。自動検査と実画面の確認結果は分けて記録する。
