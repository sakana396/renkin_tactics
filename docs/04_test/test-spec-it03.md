# テスト仕様書（反復 3）

- 文書 ID: TST-IT03
- 版: 0.1（骨組み。実装とともに書き足す）
- 対象: [反復 3 計画書](../iterations/it03/plan.md) v0.2 の範囲、[設計書 DES-IT03](../03_design/design-it03.md) v0.2

本書は Issue #60 で作成した枠に、各実装 Issue のテストケースを追記する。各実装 Issue の担当が、設計書 8.2 節の案をもとに前提・入力・期待結果を具体化し、テストコードとトレーサビリティの担当行を同時に更新する。

## 1. 方針

| 項目 | 内容 |
|---|---|
| テストケース ID | `TC-<要求ID>-<連番2桁>`。新規要求は 01 から、既存要求は反復 1・2 の仕様書を照らし、既存の最後の番号の次から振る |
| コードとの対応 | 表駆動テストを基本とし、サブテスト名にテストケース ID を入れる。正常・境界・異常を確かめる |
| 書き足し方 | 各担当が自分の要求の節に行を追加する。同じ要求を複数の Issue が担当するときも同じ節に書き足す |
| 期待値 | 実装の出力を写さず、承認済みの要求と設計から導く |
| 乱数と巻き戻し | PCG の保存・復元は実際の PCG で検証し、固定列の差し替えによる検証と分ける。巻き戻しのない既存の乱数列も保つ |
| 失敗時の状態不変 | 戦闘・Campaign・入力の配列だけでなく、履歴・乱数・敵軍の進行位置・残り回数も確かめる |
| 既存ケースの改訂 | 設計書 8.3 節に従い、ID と既存の規則の確認を保ち、元の反復の仕様書の行を直す |
| 表の取り込み | 変更した要求・ケースの行を照合し、列数・行末の区切り・表の中の空行を確認する（REV-031 F-01、REV-033 F-01・F-02） |
