- 文書 ID: TST-IT02

反復 1 の要求のテストケースは、[テスト仕様書（反復 1）](test-spec-it01.md) にある。反復 2 で書き換える反復 1 のテスト（設計書 9 章）は、ID を変えずに反復 1 の仕様書の行を直す。

## 1. 方針

| 項目 | 内容 |
|---|---|
| テストケース ID | `TC-<要求ID>-<連番2桁>`。反復 1 で使った要求（例: FR-SYS-03）の続きは、反復 1 の最後の番号の次から振る |
| コードとの対応 | 表駆動テストのサブテスト名にテストケース ID を入れる |
| 書き足し方 | 各 Issue の実装の担当が、自分の担当する要求の節だけに行を足す（AGENTS.md「並列作業の注意」）。同じ要求を複数の Issue が担当するときは、その要求の節に書き足す。節がなければ、2 章の終わりに足す |
| 種別 | 正常・境界・異常 |
| 乱数 | 当たり・外れと成長は、乱数を差し替えて決まった値で確かめる（DES-RNG-01、DES-GRW-02） |
| セーブ | ファイルを使うテストは、`t.TempDir()` のディレクトリを使う。画面のテストは、記憶の中に持つ `SaveStore` の偽物を使う（DES-UI-09） |
