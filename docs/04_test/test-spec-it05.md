## 3. 検証記録

### 3.1 Issue #99

- 指定の GOCACHE で、`gofmt -l .`（出力なし）、Linux の対象パッケージの `go vet`・`go test`、`GOOS=windows go vet ./...` が成功した。UI は変更していない。
- `go run ./tools/tccheck` は整合 OK。警告 32 件は既存の手動ケースで、追加の 2 ケースの警告はない。担当の表の 6 列と行末の区切りを確認した。
- 実装前の上限 16 で TC-FR-MAP-02-01 の 17・32 の受理が失敗した。上限 32 への変更後に成功した。
- ミュータント検査: 上限を 31 にすると 32×32 の受理が失敗、33 にすると 33 行の拒否が失敗した。BoardView の盤内判定に 16 の制限を入れると既知地形 (16,0) の検査が失敗、移動探索だけに 16 の制限を入れると移動費の検査が失敗した。4 件とも検出し、すべて元に戻してから提出前の検査を通した。

### 3.2 Issue #100

- 指定 GOCACHE・GOPROXY=off で検証。`gofmt -l .` は出力なし。Linux の対象パッケージの `go vet`・`go test`、`GOOS=windows go vet ./...` は成功。UI・cmd/renkin の Windows 向けテスト実行ファイルはコンパイル成功。
