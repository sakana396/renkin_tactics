## 3. 画面と入力（U-1〜U-6、先に承認する章）

### 3.1 共通の配置、状態と入力の優先

座標は左上を (0,0)、右・下の端を含まない。通常画面の盤面は (0,0)〜(512,512)、情報欄は (512,0)〜(832,360)、ミニマップ欄は (512,360)〜(832,512)、案内欄は現行の案内文の領域 (0,512)〜(512,576)。盤面の 1 マスは 32 px、情報と予測の文字は現行より小さくしない。予測は盤面上に置くが、通常はミニマップ・右欄・行動メニューを覆わない。相手と移動先の両方を避ける候補が盤面内にないときだけ、右欄に重ねる。クリック判定は「巻き戻し／詳細・全体図のモーダル → 予測の窓・行動メニュー → ミニマップ → 情報欄 → 盤面」。`Playing` の再生中と `Over` は新しい操作を受けない。Q は現行どおり `Playing`・`Over` 以外の戦闘の入力待ちと `Deploy` で受ける。キーが同じフレームで押されたときは現在の状態に許されたものだけを一つ処理する。

| 現行の割り当て（`game.go`） | 本書の追加案 | 衝突の扱い |
|---|---|---|
| 矢印・ホイール（Shift+ホイールで横）= カメラ | M = 全体図、Z = 次の未行動の味方、中ドラッグ = 盤面をつかむ | 既存のカメラ移動は保つ。全体図中の矢印・ホイールは無効 |
| Q = 全敵の危険範囲 | Q は全敵、敵のクリックは個別、範囲欄の「消す」は固定を一括解除 | Q を別の機能に使わない。`Selected` の敵クリックは直接攻撃を優先 |
| Tab = 情報ページ、E = 番を終える、T = 巻き戻し | I = 詳細、A・D = 予測中の武器、M・Z は上記 | Tab は詳細画面の節送りだけに変える。E と T の入口は保つ。A・D は現行の `game.go` で未使用。予測中のホイールは窓内だけ武器送り |
| 右クリック・Esc = 取消し、Space・Enter = 再生の早送り | 右クリック・Esc で詳細／全体図を閉じる | 再移動 `Canto` の取消しは従来どおり `CantoEnd`。巻き戻し表示中はその取消しを優先 |

| 状態・入口 | 出すもの／戻すもの |
|---|---|
| `Idle`・`Selected`・`Moved`・`Targeting`・`HealTargeting`・`ItemMenu`・`StaffMenu`・`Canto` で I | カーソル下に生存ユニットがあればそれを詳細に出し、いなければ選択中のユニットを出す。両方なければ開かない。詳細中の Tab は能力・武器・スキルの節を送る。閉じると元の入力状態と仮選択へ戻る |

重なったマスは全敵の塗り → 固定の縁 → カーソルの縁の順に描き、下の地形とユニットが読める透明度にする。戦死した敵は固定から外し、巻き戻し成功時は戻った盤面に生きる添字だけで再計算する。配置中はまだ出ない増援を含めない。危険範囲は ZOC を含む `Reachable` と攻撃射程で求め、UI が独自の移動費を計算しない。色・印は Q-DES07-02 の決定による。線種は色が見分けにくい場合にも移動と攻撃を分ける。

予測窓は U-3 と U-6 で **一つ** にする。窓内の座標は左上からの相対値とし、帯 (8,8)〜(408,36) に「撃破」または「危険」、名前 (16,40) と (280,40)、武器名・種類と相性 ▲▼ (16,60)〜(400,92)（武器の種類の絵は今の `WeaponIconSize` の 32 px）、HP・ダメージ×回数・命中・必殺・速さ・反撃の 6 行の表 (16,92)〜(400,184)、効くスキルと特効 (16,184)〜(400,216)、武器送りと決定・戻る (16,216)〜(400,240) を置く。文字は現行の大きさを保ち、長い武器名・スキルは各欄で折り返す。相手のマスの上には従来の「5×2 63%」の形式で文字と撃破・危険を出し、危険時には仮の移動先に赤枠を出す（UC-03、DES-UI-07）。予測の値は `Battle.Forecast` から取得し、武器の送りごとに同じ API を呼ぶ。必殺・大盾の確率を「予測後 HP」の確定値に織り込まず、今の予測の定義と同じ通常値で示す。回復の予測も同じ窓の枠を使うが、杖の選択順は変えず `HealForecast` の値を使う。位置は相手と仮の移動先の両マス（長弓の射程 2〜3 で離れる場合を含む）を避ける候補を選ぶ。複数なら相手と反対側の上下を優先する。盤面内に候補がなければ右欄全体へ置き、帯 (8,8)〜(312,40)、名前 (16,44) と (224,44)、武器と相性 (16,68)〜(304,100)、6 行の表 (16,104)〜(304,240)、効くスキル・特効 (16,248)〜(304,296)、武器送り・決定・戻る (16,304)〜(304,352) に収め直す。座標は右欄左上からの相対値で、同じ文字の大きさを保つ。その間は右欄の通常情報を隠し、予測窓の両者の名前を読む。窓の外のクリックは盤面の選択として扱い、窓内の ◀▶ と決定・戻るは窓が受ける。

重騎士の ZOC は、盤面のそのユニットの隣の通れるマスに青（自軍）または赤（敵軍）の細い角印を付ける案とする。U-1 の危険範囲と同時に出るときは危険範囲を下、ZOC の角を上に描く。隣の自軍に効かないことを、カーソルの下の移動費の説明に「相手の重騎士の隣: +1」と示す。強制停止を示す線や壁の絵は使わない。巻き戻しの下見では下見側の生存者で描く。指揮官の印は 5.4 節。いずれも Q-DES07-02・09 と E-120 の決定による。

## 4. 重騎士の ZOC（DES-BTL-11、DES-DAT-05）

### 4.1 定義と効く相手

`skills.toml` に `id = "zoc"`、`effect = "zoc"` の数値なしの兵種スキル（表示名は「通せんぼ」の案）を追加し、`classes.toml` の `armor` に `skills = ["zoc"]` を足す案とする。現行の `pavise` はガルドのキャラのスキル（`characters.toml`）であり、その定義と効果は保つ。defload は効果名・数値なし・同一効果の重複・参照の存在を検証する。自軍・敵軍とも `armor` の兵種スキルから効果を得る。敵の重騎士の装備や能力は変えない。自軍の重騎士には自軍の移動を妨げない（Q-DES07-05）。飛行などの例外は足さない。

### 4.2 費用と経路

移動者 `u` が現在の盤面で隣接マス `q` に入るとき、従来の占有と `Cost(q) >= 1` の検証後、次の費用を使う案とする。

```text
Z(u,q) = 1  相手軍で生存し、zoc を持つユニットが q と上下左右で隣接するとき
       = 0  それ以外
辺の費用(p→q) = Cost(q) + Z(u,q)
最小費用(q) = min(通れる経路の各辺の費用の和)
Reachable(u) = { q | 最小費用(q) <= u.Mov }（出発マスの費用は 0）
```

重騎士が複数いても `Z` は最大 1、隣のマスから **出る** だけなら加算せず、次に **入る** マスを改めて判定する案。重騎士のいるマスそのものには占有規則で入れない。`BoardView.reachableWithin` のダイクストラ法に同じ辺の費用を渡す。費用が正なので既存の同点処理を保つ。`AttackRange` 自体の射程は変えないが、到達できる攻撃位置は ZOC 込みで選ぶ。危険範囲・一団の集合先・敵の騎兵の再移動先・「最小の費用で近づく」経路も同じ関数を用いる。DES-AI-01 の「近さ」は自軍から逆向きに探すが、辺の費用は敵が進入する側のマスの `Cost+Z` とする（Q-DES07-08）。

| 例（平地 Cost=1） | 経路 | 計算 | Mov=3 で到達 |
|---|---|---|---|
| 相手重騎士なし | A→B→C→D | 1+1+1=3 | D に届く |
| B が相手重騎士の隣 | A→B→C（C は ZOC 外） | (1+1)+1=3 | C に届く |
| B・C が ZOC 内 | A→B→C | (1+1)+(1+1)=4 | C に届かない |
| B に相手重騎士 2 体が隣接 | A→B→C（C は ZOC 外） | (1+1)+1=3（B で +2 にはしない） | C に届く |
| B から始め C・D は ZOC 外 | B→C→D | 1+1=2（B の分は取り直さない） | D に届く |
| 自軍重騎士だけが B に隣接 | A→B→C→D | 1+1+1=3 | D に届く |

### 4.3 再移動・撃破・巻き戻し

再移動の残りは `Mov − 行動前の位置から Command.To への ZOC 込み最小費用`。行動後の `CantoReachable` は、その時点の生存者を使い、同じ残りの予算で求める。行動で相手重騎士を倒したなら、撃破直後の盤面にはその ZOC がない。例: Mov=7、平地 2 歩のうち 1 歩が ZOC 内なら行動前の費用は 3、残り 4。撃破後の平地 4 歩は届く。撃破前の ZOC 費用を行動前の残りから払い戻すことはしない。敵の再移動にも同じ境界を使う。移動＋行動＋再移動は DES-BTL-10 の一手であり、巻き戻しは行動前の位置・重騎士の生死・残り・乱数へ戻る。

## 5. 指揮官と配下（DES-AI-03、DES-DAT-05）

### 5.1 定義・検証

`maps.toml` の `[[maps.enemies]]` または `[[maps.events.enemies]]` の前線の小隊長に `commander = true`、既存の `group = "..."` と `approach = "group"`、`ai = "hold"` を付ける案。各小隊長を標的とする `trigger = "enemy_attacked"`・`effect = "charge_group"` の出来事も同じ章に付ける。既存の配下には同じ `group` を付ける。小隊長は `boss = false`、既存の兵種・武器・レベル・能力を使い、新しい兵種と章ボスの変更はしない。推奨は soldier または既存の前線兵種、レベルは同章の配下の上限 +1、能力の上乗せは同じ一団の配下と同じ `bonus` を基準に追加 0 とする（`bonus = 0` に戻す意味ではない。小隊長を倒す価値は思考の切替で作る）。Lv+1 は DES-IT06 7.3 節の章ごとの目安を超えうる（ch01 は Lv4、ch03 は Lv8、ch09 は Lv13 でボスと同じ）。その例外と理由を各章の制作記録に書く。個々の位置・武器・レベルは章の制作記録で決め、基準の測り直し後に承認する。

defload は `commander=true` に一意の `id`、`approach="group"`、空でない `group`、`boss=false` を求める。同じ到達領域で同じ `group` に生存可能な小隊長を 2 体置かない。初期配置と出来事の増援をまたぐ同名の一団は、現行 `groupKey` の領域単位で識別する。新しい小隊長不在の一団は作らない（E-121）。`tactics` には定義 ID ではなく、一団の鍵と小隊長である印・参照を渡す。章のボスと `direct` の敵には付けない。

### 5.2 生存と撃破直後の切り替え

小隊長は `ai="hold"` のまま、配下と同じ `GroupApproach` で、DES-IT06 10.2 節の集合・割に合わない相手を避ける判断に参加する。一団の有効な方式は、対応する小隊長が生存中は `group`、撃破直後から `direct` とする案。元の `Approach` は書き換えず、崩れた印を状態に保持し、小隊長の生死と合わせて有効方式を決める。印も巻き戻しで復元する（Q-DES07-10、E-120）。

DES-IT06 の「集まる先と一斉に入る判定は敵軍の番の始めに一度だけ」は **小隊長が生きている一団の判定** として残す。撃破は途中の集まりの決定を再計算するのではなく、その一団の `groupPlan`・`groupDanger`・`groupGathering`・`groupEntered` を以後の行動で参照しない切り替えとする。敵軍の番の途中で自軍の反撃により小隊長が倒れたときは、まだ動いていない配下だけがその番から `direct` を使い、動き終わった配下はやり直さない案。巻き戻しは小隊長の生死と一団の状態・印を戻す。小隊長を倒した攻撃の出来事の再生が終わるまで入力を待ち、印は撃破の出来事の時点で更新する。号令の文は出さない。

崩れた配下の `hold` は初めて行動する時点で `charge` として扱い、もう待ち続けない案。すでに一団が入った状態でも `direct` へ切り替える。初めから `direct` の敵を「ごろつき」と呼ぶ案では、新しい兵種や勢力を増やさず、章の制作記録で該当者を指定する。ごろつきには指揮関係の印を付けず、通常の敵と同じ表示にする案。これらは E-103 の解釈を E-120・E-121 で決定したものである。

### 5.3 増援・数の上限

増援の一団にも小隊長を同じ出来事の敵として入れる案。小隊長が出ない（出現マスが埋まる、敵 39 体の上限など）場合に配下だけが出るときは、その配下を `direct` として出す。小隊長が先に出て配下が出ない場合は小隊長だけでも現行の敵として行動する。出来事の列の先頭に小隊長を置き、出現に失敗した個体は先送りしない既存の決まりを保つ。離れた場所の同名の一団は別の一団として扱う（E-121）。敵の上限は同時 39 体のまま（TBD-11）。追加の小隊長で上限を超える配置や、予定した増援が頻繁に出なくなる配置は制作上の未達として直す。

### 5.4 印（DES-UI-35）

盤面では小隊長の絵の左上に金の菱形、配下の左上に同色の小点、崩れた配下には灰の割れた小点を付ける。右欄の名前の横に同じ形と「小隊長／配下／崩れ」の短い語を置く。印は別々の軍色の中でも形で判別できるようにする。小隊長の撃破の出来事に合わせて直ちに配下の印を切り替え、巻き戻しの下見は下見の盤面の状態で描く。号令の文章・線は出さない（E-118）。崩れの印は章の終わりまで残す（Q-DES07-10、E-120）。
