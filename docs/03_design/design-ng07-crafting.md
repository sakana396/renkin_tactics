## 1. 目的と範囲

前衛に守られる錬金術師の強い道具を、限られた章報酬から次の戦いに合わせて選ぶ。強さを下げず、広い爆風・遠距離・支援・回復の配分を悩ませる。新作の準備だけで行い、施設復旧・装備・品質・戦闘中の調合は扱わない。数値と操作はすべて承認前の案。1 章は既存の手持ちで始まり、初めの材料は 0 とするが、調合ボタンは表示する。

## 2. 候補と推奨

| 方式 | 遊び | 操作 | 定義データ | 規模 |
|---|---|---|---|---|
| A 共通材料を使うレシピ | 2 種の材料を競合させ、広範囲か遠距離か支援かを選ぶ。残りを次章に持ち越せる | 品を選び必要数を見て 1 個ずつ決定 | 材料・必要数・生成品を定義 | 中: 在庫・画面・保存・検証 |
| B 材料量に比例した一括生産 | 1 種の材料を選んだ品にまとめて割く。選択は簡単だが種類ごとの競合は単純 | 品と数量を選ぶ | 品ごとの単価 | 中: 数量入力と上限検証 |
| C 報酬の選択 | 勝利時に報酬の束を選び、準備で受け取る。将来の状況を見た配分変更が少ない | 勝利時に束を選ぶ | 章ごとの報酬束 | 大: 結果画面・保存・章別定義 |

**推奨 A。** 章の情報を見てから材料を割り当てられ、2 章の二つの橋、3 章の両翼の射手に応じて範囲と射程を競合させられる。量の範囲を明示でき、B の一括操作は後から検討できる。C は準備画面で何を作るか選ぶ目的に合いにくい。

### 3.1 DES-NG-18 定義と検証

材料は「鉱粉」 `ore` と「触媒」 `catalyst` の 2 種。`data/alchemy` に材料とレシピの定義を追加し、`defs` の独立した材料・レシピ目録に読み込む。章報酬には既存の item 報酬と排他的な material ID と正の count を許す。旧作の未指定は空の目録・材料報酬なし。品は既存 `items.toml` を参照する。

| ファイル | キー | 内容 |
|---|---|---|
| `materials.toml` | `id`・`name` | 材料の ID と表示名 |
| `recipes.toml` | `id`・`name`・`item`・`count`・`ingredients` | レシピ、生成品と個数、材料と必要数 |
| `chapters.toml` | 報酬の `material`・`count` | 材料 ID と個数 |

| 生成品（1 回 1 個） | 鉱粉 | 触媒 |
|---|---:|---:|
| 小さな爆弾 `bomb_small` | 1 | 1 |
| 投げ火 `bomb_far` | 2 | 1 |
| 大きな爆弾 `bomb_large` | 2 | 2 |
| 回復薬 `potion` | 1 | 1 |
| 剛力薬 `tonic_power` | 1 | 2 |
| 粘着瓶 `snare_bottle` | 2 | 1 |

`defload` は材料・レシピの空 ID、重複 ID、空名、未知の材料・出力アイテム、材料の重複、材料なし、必要数 0 以下、出力数 1 以外、報酬の未知 ID・0 以下・item と material の混在を、ファイル・位置・理由付きで拒む。値と加算は保存可能な整数の範囲で検査する。武器は出力できない。`tactics` は材料・レシピ・`defs`・World を知らず、準備の規則は `core` に置く（ADR-0002）。

### 3.2 DES-NG-19 調合と保存

共有の材料在庫は ID ごとの非負整数で、手持ちの 5 枠には入らない。準備中にレシピを指定するたび、全材料が必要数以上、生成品が存在し在庫への加算が整数上限を超えないことを検証する。成功なら必要数を同時に引き、共有の道具在庫に 1 個加える。失敗は理由を返し、材料・道具・名簿・乱数・履歴を一切変えない。乱数・成功率・品質はない。未使用の材料は章をまたいで残る。

セーブには材料 ID と個数を保存し、保存時の章・名簿・道具と一体で復元する。材料欄がない旧セーブは空在庫として読み、既存の道具を材料に変換・削除せず二重報酬を与えない。未知 ID、負数、重複、範囲外の保存値は理由付きで読み込み失敗し、現在の状態を変えない。準備中の変更の保存時点は既存の準備・章開始セーブ規則に従い、配置から準備へ戻っても変更を保つ。途中終了後は最後に保存した状態へ戻る。直接 2・3 章開始の初期化は既存の前章報酬と同じ範囲を材料にも適用し、既存の直接開始と二重に加算しない。

### 3.3 DES-NG-20 準備画面

DES-NG05 の HiRes 準備に「調合」ボタンを加え、押すと同じ画面内の重ね窓を開く。章情報は閉じれば元に戻る。材料名・所持数、スクロールできる全レシピの出力名・効果・必要数・不足数を表示し、不足の品も理由付きで見せる。行をクリックして選び、決定ボタンで 1 個作る。成功後は材料・在庫と不足表示を更新し、連続決定は押下ごとに 1 回。選択・取消しは状態を変えない。失敗時は理由を表示する。Esc・右クリックまたは閉じるボタンは重ね窓だけを閉じ、在庫選択や武器の右クリックに伝播しない。開いている間は背後の「配置へ」等を受け付けず、Enter は選択中の調合決定に限る。閉じた後は既存の操作に戻る。空のレシピ目録ではボタンを出さない。旧作の操作・表示は変えない。画面の値とクリック領域を共通にし、1088×832 内の重なりと長い名前・スクロールを試験する。

### 3.4 DES-NG-21 章の報酬と難しさ

現在は各章の勝利で回復薬 2・小爆弾 3・投げ火 1、さらに 1・2 章は剛力薬 1・粘着瓶 1。以下はいずれも直接の回復薬と 1・2 章の両道具を保ち、爆弾 4 個だけを材料に置き換える案。3 章の報酬は 3 章勝利後のため、1〜3 章の戦闘中には使えない。

| 報酬案 | 1・2・3 章それぞれの材料 | 既存の爆弾相当 | 意図と限界 |
|---|---|---|---|
| 基準維持（推奨） | 鉱粉 5・触媒 4 | 小 3 と投げ火 1 をちょうど再現（5・4 消費） | 元の組合せを選べるが、大爆弾 2 個等の新たな強い選択もある。難しさが同じとは限らない |
| 絞る（不採用） | 鉱粉 4・触媒 3 | 小 2 と投げ火 1 の計 3 個 | 章ごとに爆弾 1 個分を削り、保存や武器で補う判断を強める。3 章の指揮官への必要火力に影響 |

両案とも、既存の初期手持ち・在庫と直接報酬は保持。例えば 2 章開始の前章報酬だけなら基準維持では小 3＋投げ火 1、絞る案は小 2＋投げ火 1。3 章開始では各章の材料を使わずに残した場合は 2 章分が累積する。旧版セーブは既に持つ完成品をそのまま使う。DES-NG01 6.3 は #212 で改訂した。DES-NG-17 の直接報酬は保ち、章制作記録の旧報酬は制作時の記録として残す。FR-ITM-09 の両道具の直接報酬は保つ。

H-33 の短い試遊で選んだ品・残した材料・使用箇所・不足と理由・難しさを記録し、2 章の橋と 3 章の両翼・指揮官を確かめる。既存の爆弾を使わない自動試遊の 3 章 1/20 勝は人の難しさや調合の妥当性を証明しない。難易度維持は試遊前の見込みである。

### 3.5 DES-NG-22 行動の記録

既存の戦闘行動記録は戦闘の入力と再生用であり、準備の調合は記録形式に追加しない。H-33 は人の試遊記録に選択と残量を記す。再現は準備後のセーブの材料・道具在庫で確認する。戦闘の乱数・記録・再生と旧記録は変えない。

## 4. 決定（E-151）: すべて A

1. 調合方式: A 共通材料のレシピ（採用）／B 一括生産／C 報酬の束。
2. 材料と品: A 2 種・表の 6 品と必要数（採用）／B 爆弾 3 種だけ／C 別の組合せ・数値。
3. 報酬: A 基準維持を採用。B 絞る・C 別の配分は不採用。1・2 章の両道具は直接残す。
4. 範囲と記録: A 装備・品質は保留、戦闘記録を拡張せず試遊記録に残す（採用）／B 調合の記録も追加／C 別案。
