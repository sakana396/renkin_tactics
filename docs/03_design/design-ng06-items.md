## 1. 目的と範囲

前衛が後衛を守り、錬金術師が強い道具の使い時を選ぶ。爆弾による撃破以外に、前衛への支援と敵の進路の制御を与える。使用者の兵種制限は設けない。道具は消耗し行動を費やすため、爆弾・回復・攻撃との選択になる。文面は承認待ちである。調合と材料は #212、施設の復旧は範囲外。

## 2. 候補と推奨

距離はマンハッタン距離。持続の「次の自軍開始」は使用直後の敵軍の番を挟んだ自軍の番の開始時を指す。

| 候補 | 効果・数値と対象 | 持続 | 爆弾との違い・面白い役割 | 規模 |
|---|---|---|---|---|
| 剛力薬 | 距離 0〜3 の生存する味方 1 体の力・魔力 +4 | 次の自軍開始時に終了 | 一撃で敵を削らず、守る前衛の反撃や次の自軍開始前の戦闘を強くする。後衛から前衛を支援 | 中: 一時能力と計算・表示 |
| 粘着瓶 | 距離 1〜4 の生存する敵 1 体の移動力を 0 にする | 次の自軍開始時に終了 | ダメージなし。射程内の攻撃は可能。後衛が敵の接近を遅らせ、前衛の守る方向を選ぶ | 中: 移動・AI・範囲表示 |
| 仮設足場 | 距離 1〜3 の空いた水路 1 マスを通行可能にする | 次の自軍開始時に終了 | 新しい経路を作る。機動役と後衛で迂回できる | 大: 期限切れ時に上にいるユニットの扱い・経路・地形の保存 |
| 仮設壁 | 距離 1〜3 の空いた平地 1 マスを通行不能にする | 次の自軍開始時に終了 | 進路を塞いで前衛を補助する | 大: 経路・増援・閉塞と地形の保存 |

**推奨: 剛力薬と粘着瓶。** 反撃を強くするか、別方向の敵を一時的に止めるかの判断を加え、爆弾の範囲攻撃と役割が重ならない。どちらも行動を使い、敵を即座には倒さない。足場・壁は 2 章の橋の制約を大きく変え、地形の期限切れや増援の整合の判断が多いため今回は見送る。強さ・個数は試遊前の案である。

### 3.1 DES-NG-13 定義と検証

`data/alchemy/items.toml` に次の形で追加する案。`heal`・爆弾の 3 キー・下記 2 種の組は相互排他。既存の回復薬と爆弾の意味・検証は変えない。

```toml
[[items]]
id = "tonic_power"
name = "剛力薬"
effect = "power_tonic"
amount = 4
range = 3

[[items]]
id = "snare_bottle"
name = "粘着瓶"
effect = "snare"
range = 4
```

`effect` は上記 2 値のみ。剛力薬は `amount` と `range` が必須で 1 以上、粘着瓶は `range` 必須で 1 以上、`amount` は禁止。未対応の値、欠落、0 以下、異種の混在はキーと理由を示して読み込み失敗とする。重複 ID などの既存検証も保つ。`internal/core` が定義を tactics 固有のアイテム型に変換し、`tactics` は `defs` を参照しない（ADR-0002）。直接渡される tactics の設定にも同じ値域と排他を検証する。

### 3.2 DES-NG-14 使用と状態

既存の `UseItem` の移動後の位置から対象を指定する。共通の行動検証に加え、手持ちの存在、対象指定、盤内・生存、陣営、距離を検証する。剛力薬は本人を含む味方、粘着瓶は敵だけ。粘着瓶は距離 0 を許さない。対象のないマス、倒れたユニット、射程外、別種の対象指定、既に同種の効果がある対象は失敗し、移動・行動済み・手持ち・効果・乱数・履歴を変えない。予想も同じ検証を使う。

成功すると移動し、1 個消費し、対象に効果を付けて使用者を行動済みにする。装備・HP・経験は変えず、乱数も引かない。出来事は移動（あれば）、使用と対象・効果の付与の順。既存の再移動と番の移行を続ける。薬は基礎能力を変更せず戦闘計算時に力・魔力に +4 する。上限による切り詰めはせず、反撃・攻撃予想も同じ値を使う。杖の回復量の魔力にも +4 を使い、杖の兵種上限と不足 HP を適用する（E-150）。粘着は対象の移動予算を 0 とし、その場での攻撃・反撃や待機はできる。ZOC・射程は変えない。AI は移動可能マスの既存計算を通し、移動力 0 なら現在地だけを候補とする。再移動も 0 とする。

両効果は使用した番の次の自軍開始処理の冒頭、地形回復や入力に先立ち消える。自軍開始処理の直前までは有効。対象が倒れたらその効果は取り除く。戦闘終了時に持ち越さない。同種の重ね掛け・延長はできず、異種は対象陣営が異なるため同一対象に共存しない。敵軍はこれらを使用しない。

### 3.3 DES-NG-15 巻き戻し・記録・自動の打ち手

戦闘状態の完全な写しに対象ごとの効果と期限を含める。巻き戻しの下見・取消しは状態を変えず、決定時は消費、位置、行動済み、効果と期限、乱数、履歴を同時に戻す。番開始の期限切れも写しに含める。行動記録にアイテムの手持ち位置と対象座標を記し、使用・付与・期限切れの出来事と対象、種別、値を記録する。再生は同じ入力から同じ出来事を比較する。既存の記録の形式と再生を保つ。予想は記録しない。

既存の自動試遊の打ち手は新道具を選ばない。敵 AI も選ばない。使用しない結果は攻略可能性の下限の参考であり、人の難しさや H-33 の証明とはしない。後続で使う打ち手を追加する場合は比較条件を明記する。

### 3.4 DES-NG-16 画面と予想

行動一覧の「アイテム」は有効な対象がある新道具を持つ場合にも表示する。品目一覧に名前・個数・効果・距離を表示。選択後、移動後の位置から届く有効な味方または敵を示す。対象を仮選択すると名前、現在値と使用後の力・魔力、または移動力の現在値と使用後 0、期限を表示する。効果中の印と期限を盤面・詳細に出し、攻撃予想と敵の危険範囲も効果を反映する。対象の再選択ができ、決定で一度だけ実行。右クリック・Esc で予想→対象→品目→行動一覧に戻り、決定前の取消しは状態を変えない。対象がなくなった場合の決定失敗は理由を示す。

### 3.5 DES-NG-17 章と在庫の案

| 場所 | 案 | 意図 |
|---|---|---|
| 1 章開始 | 追加なし | 爆弾と前衛の保護を先に学ぶ |
| 1 章勝利報酬 | 剛力薬 1・粘着瓶 1 を既存報酬に追加し共有在庫へ | 2 章の準備で持たせる選択を作る |
| 2 章 | 初期配布なし。準備で報酬を手持ちに渡す | 二つの橋で片方の敵を止め、他方の前衛を強化するか爆弾を使うかを選ぶ |
| 2 章勝利報酬 | 剛力薬 1・粘着瓶 1 を既存報酬に追加 | 3 章の増援・指揮官に配分する |
| 3 章 | 初期配布・追加報酬なし | 中央と両翼で消耗品の使い時を選ぶ |

使わなかった分は通常の在庫として残る。章途中の入手や敵の所持は設けない。直接 2・3 章から始める場合も既存の前章報酬の扱いに従う。#212 の調合による供給は当時未定で、この案に含めない。（#212 で決定（E-151）。DES-NG07 を参照。）3 章の自動試遊は爆弾なし 1/20 勝であり、今回の在庫追加が難易度を適切にする証拠ではない。承認後に新道具の使用・未使用と消耗した名簿を含む試遊を行う。

## 4. 決定（E-149）: すべて A

剛力薬・粘着瓶の 2 種、+4・移動 0、次の自軍開始まで、味方単体・敵単体、射程 3・4、1・2 章の勝利報酬に各 1 個、同種の重ね掛け不可、敵は使用しない。杖の回復量にも効く（E-150）。
