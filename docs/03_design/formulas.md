## 1. 読み方と有効な版

この文書は読むための一覧であり、規則を決定する原本ではない。各行の出典を正とする。**反復6の承認と該当機能の実装が完了するまでは、2〜5章の現行式が有効**。6章の「反復6から」は未承認の予定であり、現行の攻撃やセーブがすでにその式へ変わったことを意味しない。途中版はIssueごとに実装済みの範囲を記録し、全体が新式へ移ったと誤解させない。新式の変更はまず DES-IT06 を改訂し、本一覧はその決定を転記する。

Aは攻撃者、Dは受け手。距離は `abs(A.X−D.X)＋abs(A.Y−D.Y)`。`max` は大きい方、`min` は小さい方、`clamp(x,a,b)=min(b,max(a,x))`、`floor` は切り捨て。式の割算は非負の整数で行い、端数はその割算の位置で捨てる。命中判定の和には平均の整数除算を挟まない。

## 2. 現行の攻撃・相性・地形（反復1〜5）

### 2.1 式

| 値 | 現行の式・条件 | 出典 |
|---|---|---|
| 相性t | 剣は斧に、斧は槍に、槍は剣に有利。有利＋1、不利−1、それ以外（弓・杖含む）0 | DES-IT01 3.5、DES-BTL-05。杖はDES-IT02 4.4 |
| 攻撃力 | A.Str＋A.Weapon.Might＋t | DES-BTL-05 |
| 通常ダメージ | max(0,攻撃力−D.Def−受け手の地形.Def) | DES-BTL-05 |
| 命中 | A.Skl×2＋武器.Hit＋15t＋鼓舞補正＋狙撃補正 | DES-BTL-05、DES-SKL-01 |
| 回避 | D.Spd×2＋受け手の地形.Avoid＋鼓舞補正 | DES-BTL-05、DES-SKL-01 |
| 表示命中率H | 命中−回避を**全補正後に一度だけ**0〜100へ収める | DES-BTL-05 |
| 当たるか | 0〜99の乱数r1,r2を引き、r1＋r2 < 2H | DES-BTL-05、DES-RNG-01 |
| 追撃 | 攻撃開始時の速さ差≧4なら速い側が1回追加。守備側は反撃可能な場合だけ | DES-BTL-05・06 |
| 反撃 | 守備側が生きていて、装備が杖でなく、両者の距離がその武器のmin〜maxに入る | DES-BTL-06、DES-HEL-01 |
| 攻撃順 | Aの1撃→可能ならDの反撃→速い側の追撃。どちらかが倒れたらそこで終了 | DES-BTL-06 |
| HP減少 | max(0,現在HP−最終ダメージ)。EventStrike.Amountは残HPでは切らず、算出ダメージ | DES-BTL-06、DES-EVT-01 |

Hは判定に使う表示値であり、実際に当たる確率への補正換算を表示しない。外れでも命中乱数を2個消費する。予測は乱数を引かず、戦死で途中終了しないと仮定した1撃ダメージと回数を出す（DES-BTL-07）。

### 2.2 地形と移動

| 地形（本体値） | 入る費用 | 守備 | 回避 | 番開始の回復率 | 出典 |
|---|---|---|---|---|---|
| 平地 | 1 | 0 | 0 | 0 | DES-MAP-01、DES-DAT-02、terrains.toml |
| 森 | 2 | 1 | 20 | 0 | DES-MAP-01、DES-DAT-02、terrains.toml |
| 山 | 3 | 2 | 30 | 0 | DES-MAP-01、DES-DAT-02、terrains.toml |
| 砦 | 1 | 2 | 20 | 20% | DES-MAP-01・02、DES-DAT-02、terrains.toml |
| 壁 | 0（通行不可） | 0 | 0 | 0 | DES-MAP-01、DES-DAT-02、terrains.toml |

移動費は入るマスのCostの和で、出発マスの費用は数えない。最小費用がMov以下のマスへ移動可能。味方は通過可・停止不可、敵は通過不可。Cost=0は通れない（DES-BTL-03）。反復5の32×32化もこの式は変えていない（DES-MAP-05）。

## 3. 現行スキルと乱数（反復1〜5）

| スキル | 条件・式（本体値） | 予測と出典 |
|---|---|---|
| 鼓舞 inspire | 生存する同陣営の持ち主から距離2以内、持ち主自身を除く。命中＋10・回避＋10。複数の持ち主なら足す | 移動後位置で計算。補正を含めて表示。DES-SKL-01 |
| 大盾 pavise | 命中時だけ0〜99の乱数を1個引き、30未満ならダメージを半分・切捨て | ダメージは半減前を出し「大盾30%」。DES-SKL-01、DES-BTL-05・06 |
| 怒り wrath | 各撃直前のHP≦floor(最大HP/2)なら命中した撃は必ず必殺。通常ダメージ×Multiplier（本体3） | 開始時の条件を表示。現行には一般の必殺率・必殺乱数はない。DES-SKL-01 |
| 狙撃 snipe | 自分からの攻撃で移動前位置=Toのとき、その攻撃・追撃の命中＋20。反撃では無効 | 命中へ算入。DES-SKL-01 |

現行の各撃は命中2個→命中かつ受け手が大盾なら大盾1個→ダメージとHP。怒り自体に乱数は使わない。必殺と大盾が重なったら **3倍してから半減・切捨て**。攻撃の全撃が終わった後、経験でレベルが上がるときだけ成長乱数を引く。予測・失敗・取消しは引かない。巻き戻しはPCG状態も戻す（DES-RNG-01、DES-RWD-03）。

| 例 | 途中式 | 結果・出典 |
|---|---|---|
| F5 鼓舞と狙撃 | 技9・鉄弓命85、静止で狙撃20、鼓舞10。相手速4・森避20・鼓舞10。命中18＋85＋20＋10=133、回避8＋20＋10=38、H95 | 移動した自発攻撃はH75、反撃もH75。DES-SKL-01 |
| F6 怒りと大盾 | HP11/最大22、通常9。11≦floor(22/2)=11、怒り9×3=27。大盾が出たらfloor(27/2)=13 | 先に通常を半減して3倍する12とは異なる。DES-BTL-05、DES-SKL-01 |
| F7 奇数最大HP | HP11/最大23なら11≦floor(23/2)=11で怒り、HP12なら条件外 | DES-SKL-01 |

## 4. 現行回復・経験・成長（反復1〜5）

### 4.1 回復

| 種類 | 基本量と実回復量 | 条件・出典 |
|---|---|---|
| 回復薬 | min(Item.Heal,最大HP−現在HP)。本体Heal=10 | 自分に使用、満タン不可、Countを1減らす。経験なし。DES-ITM-01 |
| 杖 | min(Weapon.Heal,最大HP−現在HP)。癒やしの杖Heal=10 | 生存する別の味方、射程内、残回数あり、満タン不可。1回消費、経験10。DES-HEL-01・02 |
| 砦 | min(floor(最大HP×HealPercent/100),最大HP−現在HP) | 自分の陣営の番開始、経験なし。DES-MAP-02 |

薬・砦・杖の回復は命中乱数を引かない。杖だけ経験による成長乱数の可能性がある。杖の本体MaxUses=15、各章のNewで満タンに戻り章をまたいで回数を持ち越さない（DES-HEL-01、DES-DAT-02）。

| 項目 | 現行規則 | 出典 |
|---|---|---|
| 攻撃の経験 | 流れに加わり生き残った自軍が、相手戦死なら30、それ以外で自分の1撃以上命中なら10、それ以外1。0ダメージ命中も当たり | DES-GRW-01 |
| 回数 | 攻撃・反撃・追撃をまとめた流れで1回だけ。30と10を足さない | DES-GRW-01 |
| 経験対象 | 自軍かつLevel1〜19。倒れた自軍、敵、Level0・20は得ない | DES-GRW-01・02 |
| レベルアップ | 経験＋獲得量≧100ならLevel＋1、経験から100を引く。上限20では余りを捨て経験0 | DES-GRW-02 |
| 1回のレベル数 | 現行は経験≦99、追加≦30なので最大129、上昇は1レベルまで | DES-GRW-02 |
| 成長 | HP→Str→Skl→Spd→Defの順に0〜99を1個ずつ。各乱数<その成長率なら＋1 | DES-GRW-02・03、DES-RNG-01 |
| 成長の端 | 0%なら上がらず100%なら必ず上がるが、どちらも引く。全不成長でも引き直さない。Movは上がらず能力上限なし | DES-GRW-02 |
| HPの成長 | 最大HPが1上がれば現在HPも1上げる | DES-GRW-02 |

## 5. 現行の敵の思考（反復1〜5）

| 項目 | 比べ方の要点 | 出典 |
|---|---|---|
| 候補 | 移動可能な各マスと射程内の生存自軍の組 | DES-AI-01 |
| 優先1 | 通常Damage×Count≧相手HPなら撃破可として優先 | DES-AI-01、DES-BTL-07 |
| 優先2 | 与えるDamage×表示HitRate×Countが大きい候補 | DES-AI-01 |
| 優先3 | 反撃のDamage×表示HitRate×Countが小さい候補 | DES-AI-01 |
| 優先4・5 | 自軍添字が小さい→移動先Yが小さい→Xが小さい | DES-AI-01 |
| 候補なし | Chargeは最も近づけるマス、Holdは動かない。Holdも攻撃できれば攻撃しChargeへ | DES-AI-01 |
| 近さ | ユニットを除いて、生存自軍のどれかまでの地形費最小値。出発地を数えず到着地費を数える。小さくできないなら止まる | DES-AI-01 |

必殺・大盾・実際の2乱数命中確率は評価に数えず、乱数も引かない。反撃できなければCount=0。必殺なしの撃破可は命中を保証しない。範囲表示もAIの行動確約ではない。

例 F12: 相手HP12、候補a=Damage6・H80・Count2、候補b=Damage10・H90・Count1なら、aは6×2=12で撃破可、bは10で不可。与える積はa=960、b=900なのでaが先。候補c=Damage6・H80・Count2でaと同じなら、反撃の積a=5×70×1=350、c=4×60×1=240でcを優先する（DES-AI-01）。

## 6. 反復6から（DES-IT06の決定を参照する予定表）

**この章は現行式を上書きしない**。規則・数値の決定と改訂は [DES-IT06](design-it06.md) が持つ。本章の式はその案を読むために転記したもの。式の食い違いがあれば、参照先と本表を合わせてレビューする。

## 7. 検算と更新の手順

本版のF1〜F12、参照先DES-IT06の数値例、鉄の重さと仲間の力、全兵種の参考値、敵レベル表の元になる現行bonus範囲はリポジトリ外の `scratchpad/verify_des06.py` で検算した。スクリプトは製品やテストケースの実装ではなく、計算例と設計の整合を確かめる補助である。実装後はIssueごとの単体テスト・手動試遊を別に記録する。

式を変える場合は決定を持つ設計IDを先に改訂し、式の一覧・計算例・試験仕様・traceabilityを照合する。現行と予定の見出しを一括で消すのは反復6の該当実装がそろった時点とし、過去の設計書は変更しない。
