## 1. はじめに

### 1.1 目的

本書は、ゲーム「レンキン・タクティクス」が満たすべき要求を定義する。設計・実装・試験は本書の要求 ID を基準に行い、トレーサビリティマトリクスで対応を管理する。

### 1.2 範囲

本書はゲーム全体の要求を扱う。各反復で扱う要求は、反復計画書（`docs/iterations/itNN/plan.md`）で選ぶ。初期の範囲では錬金を作らない（E-07）。錬金の要求は 3.7 節に台帳として置き、優先度を W にする。

（v0.9）反復 8 から、リポジトリの主題を新作「古代都市の復旧」にする。旧作（小国アルケアの物語。定義データ `data/base`、9 章）は、戦闘の基盤の試験用として残す（E-130）。本書で「新作」は定義データ `data/alchemy` で遊ぶ作品を、「旧作」は `data/base` で遊ぶ作品を指す。錬金のうち爆弾（FR-ITM-04〜07）と、画像・音（FR-SYS-07〜09）は、反復 8 で範囲に入れる（E-130・E-134・E-137）。CST-05・7 章の「初期の範囲では作らない」は、初期の範囲についての記述として残す（錬金は E-130・E-132、画像・音・48 px は E-137）。次の箇所は旧作に合わせて書いた文面で、変えておらず、新作に合わせて改めるまでは旧作の要求として読む。FR-CMP-01 と TBD-01 の 9 章、FR-CMP-03 と TBD-04 の出撃の人数と枠・仲間の総数、FR-CMP-08 の例（帝国の側から味方になる将）、FR-CMP-09 の括弧書き「守備隊の隊長」、FR-UNT-07 のエルザ、FR-ITM-03 と TBD-06 の初めの持ち物と報酬、CST-03 の「CON-001 3 章のプロット」、NFR-01・02 と TBD-11 の 46 体（自軍最大 7・敵 39）。これら以外の要求は、旧作と新作の両方に適用する。新作の章の数は 20 章である（E-134。TBD-01）。錬金アイテムの種類は FR-ITM-08〜11、章の間の調合と FR-ALC・TBD-07 の見直しは #212 で扱う（v0.10）。

## 2. 全体の記述

### 2.1 製品の位置付け

PC で動く 1 人用の 2D のシミュレーション RPG。章立てのキャンペーンで、グリッドのマップの上でユニットを動かして戦う。体験の軸は「キャラの強みを見つける」「大きなマップとギミック」「錬金で備えても手ごわい」「単調にしない」（CON-001 2 章）。姉妹プロジェクト「ふしぎ錬金」の戦闘の中心の部分を作り込み、あとでふしぎ錬金に戻す（E-01、E-02）。

### 2.2 製品の主な機能

```mermaid
flowchart LR
  CMP[キャンペーン<br/>章の準備・章の結果] --> BTL[戦闘<br/>番・攻撃・命中]
  BTL --> CMP
  UNT[ユニット<br/>クラス・成長・スキル・支援] --> BTL
  MAP[マップ<br/>地形・ギミック・勝利条件] --> BTL
  ITM[アイテム<br/>武器・消耗品・爆弾] --> BTL
  ALC[錬金<br/>初期の範囲の外] -.-> ITM
  DAT[定義データ] -.-> UNT
  DAT -.-> MAP
  DAT -.-> ITM
```

### 2.3 利用者

| 利用者 | 特性 | 主な関心 |
|---|---|---|
| プレイヤー | ファイアーエムブレムのような戦術ゲームを好む | キャラの強みを見つけて生かすこと、マップの解き方 |
| 開発者 | 本プロジェクトの保守者。ふしぎ錬金の開発者でもある | テストしやすさ、文書とコードの対応、ふしぎ錬金に戻しやすいこと |

- 開発・試験の環境は WSL2（WSLg）と Windows

## 3. 機能要求

### 要求の書き方

- **優先度**（MoSCoW）: M = 必須、S = あるべき、C = あると良い、W = 初期の範囲では作らない（あとの反復で範囲に入れる）
- **検証方法**: T = テスト、D = 実演、I = 査閲（文書やコードを読んで確認）、A = 分析
- **TBD**: 未決の値。9 章の一覧で管理する
- 根拠の欄が「補」の要求は、企画書と要求抽出記録に直接の根拠がなく、Claude Code が FE の一般的な形や、ふしぎ錬金の SRS から補ったもの（8 章の「補った要求」の表）。開発者は 22 件すべてを残すと決めた（E-11）
- 戦闘で起きたことを出来事として記録するしくみ（ふしぎ錬金にある）は、作り方の判断なので要求にせず、反復 1 の設計で決める（E-11）
- 根拠の「CON-001 x 章」は、企画書の文面（E-10 で承認）を指す
- （v0.9）本書が引く CON-001 の章番号は、CON-001 v0.7（承認 E-141）の番号である。v0.6 からの対応: 旧 3 章の旧作のプロットは 3.6 節、旧 4〜8 章は 5〜8・10 章、旧 9・10 章は 11・12 章（新しく 4 章「規模と章立て」と 9 章「見た目と音」が入った）
