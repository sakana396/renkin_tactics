## 1. 対象と根拠

反復 2 の実装は終わり、開発者がその版を遊んだ。E-35 の発言を評価の根拠にする。E-35・E-36 の要点の文面は確認待ちである。今回、git・gh とネットワークは使わず、PR と CI の結果は既存のレビュー記録を参照した。CI の再確認や手動テストの再実施はしていない。

「楽しかった」という感想は得られたが、3 章のクリア、遊んだ時間、離脱とロストの両方の評価は記録されていない。実装完了と、計画書の評価を含む完了条件の充足を区別する。判定の区分は IT01-RETRO と同じとする。

## 3. ふしぎ錬金に戻す口の増分（H-04）

反復 1 の公開 API の個数は管理役の調べの時点の値である。次の表は反復 2 で増えた接続内容を整理したもので、同じ基準で API 全体を再集計した値ではない。

| 増分 | 結ぶ口への影響 | 根拠 |
|---|---|---|
| 経験と成長 | `Growth` と、`UnitSetup`・`Unit` の `Level`・`Exp`・`Growth` を渡す。敵は Lv 0。結果の能力・経験を `Units()` で読み出す。成長させない場合は Lv 0 を使える | DES-IT02 4.3 節、REV-022・REV-028 |
| アイテムの識別 | `Item.ID` を渡し、手持ちを ID に戻す。tactics 自体は ID を比べない。H-04 で挙げた ID の課題のうち一部を満たした | REV-022・REV-028 |
| 杖と回復 | `Staff`、`Weapon.Heal`・`Uses`・`MaxUses`、行動 `Heal`、`HealForecast`、誤り 3 つ。回復量と最大回数を渡す。残り回数は章内だけで、World へ持ち越す口は作っていない | DES-IT02 2・4.4・4.5 節、REV-024・REV-027 |
| 表示 | `EventExp`・`EventLevelUp`、`Event.Level`・`Gains`、回復の予測と杖の表示を移す必要がある。`EventHeal` は使い回す | REV-022・REV-032・REV-033 |
| 独立性 | tactics は引き続き標準ライブラリだけに依存し、World・defs・キャンペーンを知らない | ADR-0002、REV-022・REV-024 |

**提案**: H-04 の判定は「一部」のままとする。接続内容は増えたが、独立性は保っている。キャンペーンやセーブをふしぎ錬金へ移すことは決めていない。勝ち負け・アイテム効果・自動戦闘などの差は残る。ADR-0002 の改訂は IT01-RETRO 3 章の提案として別に承認を受ける。
