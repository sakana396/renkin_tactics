- 版: 0.2（承認（E-37））

本書と DES-IT03 v0.2、反復 1・2 の振り返り、E-35・E-36 の要点は、REV-034 の指摘と開発者の回答を反映した形で承認された（E-37）。新規要求の追加と SRS・ユースケース・既存設計への反映は別の改訂で行い、実装着手の前提とする。

## 1. 目的

役割の尖りと今の難しさを保ちながら、ミスを巻き戻して動かし方を考え直せるようにする。あわせて、出撃前に場所を入れ替え、最初からキャラの強みを生かせるかを確かめる（E-35・E-36）。

## 2. 確かめたい仮説

| ID | 仮説 | 確かめ方 | 関連 |
|---|---|---|---|
| H-09 | 章ごとに 10 回の巻き戻しがあると、ミスのたびに章を最初からやり直さず、難しさを楽しみながら別の動かし方を試せる | 巻き戻した理由・戻した手数・変えた行動・その章の使用回数・章をやり直した回数を記録する。回数が足りたか、緊張が薄れたかも聞く | FR-BTL-10、E-32、E-35・E-36 |
| H-10 | 出撃前に場所を入れ替えられると、役割を考えて最初の配置を選べ、準備の操作でも迷わない | どのユニットをどこへ移し、最初の動きにどう効いたかを記録する。配置・準備への戻り・戦闘開始を迷わず選べたかを聞く | FR-CMP-11、FR-UNT-03、E-35 |
| H-11 | 自軍・敵軍の行動を一つの一覧で選べると、戻る場所と消費する回数を取り違えない | 自軍の行動前、敵軍の途中、主人公が倒れる前を選び、意図した状態かを聞く。1 回で何手戻したかと残り回数の理解を記録する | FR-BTL-10、IF-01、E-36 |

反復 1・2 の未検証の部分は、両振り返りの確認点に従って次の遊びで記録を補う。新しい機能の検証と、成長・役割・物語の評価を分ける。

## 4. 作らないもの

- 新しい章・マップ・敵・仲間・スキル、クラスの能力と成長率の再調整、敵の強さの変更（Q-IT02-02）

- JSON のキー検証の修正、Side の新しい検証、ADR-0002 の移植用の口の追加、性能の本格的な調整（Q-IT03-08・Q-IT03-10）。履歴の量と操作の待ち時間は試作で測る

- Linux の手動確認（TC-NFR-03-04）。未実施を残し、先の反復へ送る（Q-IT03-09、E-37）
