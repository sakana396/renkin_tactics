# 反復 3 の振り返り: 巻き戻しと出撃の配置

- 文書 ID: IT03-RETRO
- 版: 0.1（案。人の承認待ち）
- 作成日: 2026-10-23
- 入力: IT03-PLAN v0.2、DES-IT03 v0.2、E-35〜E-39、REV-034〜REV-040、IT01-RETRO、IT02-RETRO、管理役からの PR #69 と addrev.sh の事故報告

## 1. 対象と根拠

開発者が Windows で `renkin-it03.exe` を遊んだ E-39 を評価の根拠にする。実装の確認は REV-036〜REV-040 とテスト仕様書に、今回の手動確認の結果は TST-IT03 3 章に残す。判定は反復 1・2 と同じ「成り立った」「一部」「成り立たない」「未検証」とする。

巻き戻しと配置を使い、3 章をクリアした。表示や動作におかしいと感じた所はなかったが、巻き戻しで意図した戻り先が分からなかった。計画書の完了条件のうち、同じ行動で同じ結果になることなどの個別の手動確認、遊んだ時間と詳しい行動記録は不足している。反復 3 を締めて次へ進むことは E-39 で了承されたが、未確認を合格に変えない。本書の判定と追記した既存設計の文面は、管理役が人の承認を得てレビュー記録に残す。

## 6. 反復 4 と SRS への変更点の提案

SRS・計画書は今回変更しない。E-39 は次の 4 点を反復 4 の計画・設計にまとめ、案ができてからまとめて承認を受ける進め方を了承した。以下は実装済み・設計承認済みを意味しない。

| 対象 | 要望・提案 | 根拠 |
|---|---|---|
| 巻き戻しの盤面プレビュー | 一覧で行を選ぶと、その行動前の盤面に切り替えて見せる。決定で戻し、取消しで今の盤面に戻る | E-39「合っている（推奨）」、H-11。プレビュー中に戦闘・回数を変えない具体設計と確認方法を次で定める |
| 騎兵の絵 | 馬に乗る騎兵とアーマーを見分けられる絵にする | E-39 は「騎士」と呼んだが、クラス ID は cavalier、名は「騎兵」。僧侶の絵とは別の要望 |
| 配置中の敵の攻撃範囲 | 配置を選ぶときにも敵の攻撃範囲を見られるようにする | E-39、H-10。表示と操作の案を反復 4 で承認に回す |
| 増援の予兆 | 増援が急すぎるため、分かるかもしれない程度の予兆を出す | E-39「予兆を醸してわかるかもくらいにしてあげてほしい」。時機・場所・見せ方は未決定 |

巻き戻しで緊張感が薄れた評価も次の遊びで追う。回数や難易度・能力の変更は今回決めない。JSON の正確なキー照合・重複拒否、Setup の Side の検証、ADR-0002 の改訂、履歴の量と待ち時間の測定も残した課題であり、上の 4 要望の進め方の了承をこれらの設計変更の承認に広げない。

## 7. 確認したい点

E-39 で反復 3 を締める進め方は了承された。H-09〜H-11 の判定と未確認の記録、既存設計への説明の追記は、本書と変更文面を管理役が人に示し、承認をレビュー記録に残す。反復 4 の案は別途まとめて承認を得る。
