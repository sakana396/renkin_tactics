## 3. 今回の新しい操作（U-1〜U-6、D-1、G-1）

| 操作 | 内容 |
|---|---|
| Q | 敵全体の危険範囲を出す・消す |
| 敵を左クリック（ユニットを選んでいないとき） | その敵の範囲を固定する（橙の線と金のピン）。もう一度押すと外す。右欄の「消す」で全部外す |
| 敵にカーソルを合わせる | その敵の範囲を青白の線で出す |
| M | 全体図を開く・閉じる。地図をクリックするとそこへ飛ぶ |
| Z | まだ動いていない次の味方へ移る |
| 中ボタンのドラッグ | 盤面をつかんで動かす |
| I | カーソルの下（または選んでいるユニット）の詳しい画面。能力・手持ち・全武器・スキルを 1 枚で見る |
| 攻撃の予測で A / D | 使う武器を切り替える（窓の ◀▶ のクリックやホイールでもよい） |
| 盤面の印 | 右下が装備中の武器、左上が小隊長・配下・崩れた配下の印 |
| 重騎士の ZOC | 相手の重騎士の隣のマスに入ると移動費が +1。敵の重騎士も自軍の重騎士も、相手に対して効く |
