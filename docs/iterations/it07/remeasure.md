### 観測の限界

1. `EventMove` は出発と到着だけを持ち、中間経路を持たない。#174の記録のZOCは**両軍の着地点が相手の生存重騎士の隣だった回数と、その着地点の加算1**だけで、途中で通ったマスの全進入回数・全移動費ではない。#188で、最小費用の経路に基づく計測を8章に足した（この1は#174の値の定義として残す。実際に通ったマスの列は記録がないので、8.4の限界が残る）。
2. 両打ち手の自軍は再移動を選ばず、その場で終了する。敵の再移動は移動イベントには含み、#174ではイベントに再移動専用の種類がないため通常移動と区別した件数にしなかった。#188で、同じ番に同じユニットが攻撃・回復・待機をしたあとの移動を再移動として区別した（8章）。移動/攻撃の位置を原記録で確認できる。再移動の境界規則は既存の#173と今回の通しの失敗試験で別に確認した。
3. 賢い打ち手の観測には、後で巻き戻した試行も含む。ターン内の記録は複数試行をまとめたもので、最終採用経路の入力ログではない。小隊長撃破時の崩れ一覧には以前崩れた別の一団も含むため、切替人数として合計しない。
4. 未出現は「全試行で一度も出なかった個体」。巻き戻す前だけ出た個体は未出現に含めない（旧28試遊・新47試遊では、そのような個体が最終ユニット一覧から消えていた）。#188で、最終経路と全試行を区別した（8章。新版の47試遊は#174の数と一致）。発火ターン/陣営・敵番到達を使った試行後の分類も分岐を統合した参考値で、上限と位置詰まりを断定しない。今の打ち手には巻き戻しがなく、この分岐の混同はない。
5. ZOCのスキル名は旧版互換のため本体の「通せんぼ」で照合する。名前を変える場合は計測器も見直す。

### 8.1 計測の定義と対象経路

coreの公開イベントも状態も変えず、計測器（`internal/core/remeasure_path_it07_test.go`）だけで取る。`EventMove` の出来事の写しから移動者を出発点へ戻した「移動の直前の盤面」を作り、`tactics.Reachable` と同じ規則（入るマスの地形の費用＋相手軍の生存重騎士の隣への加算1、相手のいるマスには入れず、味方のマスは通り抜けられる）で、出発点から到着点までの最小費用の経路を求めて数える。対象は両軍のすべての `EventMove`（通常の移動と再移動）。

| 値 | 定義 |
|---|---|
| 追加費用 | ZOCを数えた最小費用 − ZOCを数えない最小費用。ゲームの規則上の正確な値 |
| 入る回数の下限・上限 | 最小費用の経路のうち、ZOCのマスに入る回数が最少・最多のもの。到着点を含み出発点を含まない。実際の経路は記録がないので幅で示す。上限は追加費用以下（全920試遊で確認） |
| ZOC必須の移動 | 下限が1以上（最小費用の経路のすべてがZOCに入る）の移動。ZOC可能の移動は上限が1以上 |
| 再移動 | 同じ番に同じユニットが攻撃・待機をしたあとの移動（回復を受けた側は数えない。番の始まりと巻き戻しで印を消す。番の陣営と違う側の反撃は数えない）。自軍の打ち手は再移動を使わない |
| 全試行 | 賢い打ち手が巻き戻した試行を含め、観測した全部 |
| 最終経路 | 巻き戻しのたびに、戻したターンの最初の行動より後の記録を捨てて残ったもの。賢い打ち手が戻り先を通知する（`autoPlan.OnTurnStart`・`OnRewind`。試験用の打ち手だけの変更で、ゲームの結果・乱数は変えない） |

最小費用でない遠回りの経路は数えない（ゲームは到着点の最小費用で移動を許すため、移動費の定義に含めない）。

### 8.4 残る限界

1. 実際に通ったマスの列は取れない。coreに経路の記録がなく、移動は到着点だけで検証される（DES-BTL-03）。入る回数は最小費用の経路の幅、追加費用は到着点の最小費用の差としてだけ正しい。実際の経路をそのまま記録するには `EventMove` か状態へ経路を足す必要があり、設計の決定事項（DES-EVT-01・DES-BTL-03）に及ぶため、人の承認なしには実装しない。必要になれば「設計への提案」として出す（PR の説明）。
2. 再移動は、同じ番に同じユニットが攻撃・待機をしたあとの移動という推定。`EventHeal` は回復を受けた側を指すので使わない。杖や道具のあとの再移動（回復役の騎兵）は区別できない。コマンドの種類（`CantoMove`）をイベントから確かめる方法はなく、敵の `enemyRetreat` による再移動（攻撃後）は区別できる。
3. 最終経路は、賢い打ち手の巻き戻しの戻り先のターン番号の通知に基づく。巻き戻した試行の内部の別の分岐（同じターンの複数回のやり直し）は、最後の1本だけが残る。
4. 計測は新版だけ。旧版はZOCの規則がないので経路の値は0で、旧新の勝敗比較（#174）の定義は変えていない。
