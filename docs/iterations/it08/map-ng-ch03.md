## 1. ねらい

浄水施設を奪い返し、水を故郷へ流す。前衛で中央を押し、両翼の壁の向こうの射手へ遠くから投げ火を使うか、兵を割いて倒すかを選ぶ。1章の密集への大爆弾、2章の橋を渡る敵への範囲爆弾と異なる使いどころを作る。

## 2. 全定義

18×18、左上 (0,0)。出撃枠は (8,16)、(7,15)、(9,15)、(8,14)、(7,16)、(9,16)。詳細な地形は `data/alchemy/maps.toml`。

### 2.1 地形の意図

中央は開け、y=7 の x=3〜5・12〜14 に壁がある。両翼の射手への直進を阻み、壁越しの投擲と回り込みを比較させる。北の (8,1)・(9,1) は浄水施設。

### 2.2 初めの敵

10体。南の野盗 (4,11)、剣士 (13,11)、槍兵 (6,9)、野盗 (11,9) は突撃。射手 (3,6)・(14,6)・(8,3)、槍兵 (7,5)、剣士 (10,5) は待つ。一般兵は Lv3、力・技 +1。施設の指揮官は (8,1)、Lv5、遺物の槍、HP +8・力 +3・技 +2・速さ +2・守備 +2、待ちのボス。

### 2.3 増援

4ターン目に (2,2) の野盗、(15,2) の射手、(14,2) の槍兵が突撃する。

### 2.4 敵の動き

南の4体が接近し、両翼の射手と中央の守りが進撃を妨げる。指揮官は攻撃できる相手がいれば施設を離れる。

### 2.5 勝ち負けと報酬

指揮官撃破で勝ち、アオイの敗北で負け。報酬は回復薬2・小さな爆弾3・投げ火1。加入はない。

## 3. 数値の根拠

射手のHPは12、投げ火は10なので一撃では倒れず武器で仕留める必要がある。指揮官はHP32、速さ7でダインに追撃し、施設の守備と回復も受ける。爆弾で削る判断が重要になる。

## 4. 爆弾の使いどころ

(3,11) から (3,6) の射手へ投げ火を投げると距離5、半径0で10ダメージ。間の (3,7) は壁。敵は動くため実戦で同じ位置とは限らず、前衛と射手の位置を見て選ぶ。中央の敵は離れているため、複数を狙うには接近後の配置と味方の巻き込みを考える。

## 5. 想定する攻略

ダインで中央の突撃を受け、トーリとネムで削る。アオイとハルは回復と投げ火を分担し、両翼の射手を制して北へ進む。4ターン目の増援と指揮官の追撃を見て進む。

## 6. 自動の試し遊び

TC-DES-NG-06-17 は `NewCampaignAt` の3章開始状態（前章の報酬と加入を含み成長なし）、離脱、爆弾を使わない打ち手、40ターン、seed 1〜20。経路 (8,10) → (8,6) → (8,3)。実測 **1勝 / 20**、基準は1勝以上。19件中18件が時間切れ、1件が敗北。指揮官を残して時間切れが多い。爆弾を使わない単純な打ち手による最小限の到達確認であり、人の攻略可能性や難しさの十分な証明ではない。
