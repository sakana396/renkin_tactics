開発者は、反復 8 を試作ブランチを土台に進め、リポジトリの主題を新作「古代都市の復旧」にすると決めた（E-130）。試作ブランチには、錬金の爆弾・新作の 1〜3 章のデータ・画像と音・1 マス 48 px の表示・準備の画面の作り直しがあり、独立レビュー（REV-107〜110）を通っている。ただし企画・設計の文書はすべて未承認で、SRS・企画書・計画書は旧作（小国アルケアの物語）のままである。開発者は、試作ブランチからは**仕組み（環境）を取り込み、1〜3 章のマップと配置は作り直す**とし、Claude が画像を生成できる環境も作ると決めた（E-131）。本書は、その文書を承認して本線（main）に入れ、1〜3 章を作り直して通しで遊べる形にし、錬金の仕組みを広げる範囲と順番を示す。

## 1. 目的

1. **文書を本線にそろえる**: 企画書・計画書・SRS を新作に合わせて改訂し、試作ブランチの設計メモを承認して正式な設計書にする。ふしぎ錬金に戦闘を戻す目的（E-02）は残す（E-130）
2. **試作ブランチの仕組みを main に入れる**: まとまりごとの PR に分け、それぞれ承認された文書を根拠にする（E-130）。1〜3 章のマップと配置は取り込まず、キャラ・アイテムの定義は仮として使う（E-131）
3. **1〜3 章を作り直して遊べる形にする**: マップと配置を設計から作り直し（旧作と同じく制作記録を残す）、会話・絵・音・準備の画面をそろえ、新規から 3 章の終わりまで通しで遊べるようにする
4. **Claude が画像を生成できる環境を作る**: OpenAI の画像生成 API を呼ぶ道具を作り、指示文の組み立て → 生成 → 透過・縮小 → 台帳（`ASSETS.md`）への記入を Claude が回せるようにする（E-131）
5. **錬金の仕組みを広げる**: 爆弾の次の錬金を、企画の軸「錬金術師は後衛で、前衛に守られながら強い道具を使う」（CON-DRAFT-NG01 1 章）に沿って足す
6. **反復 7 の持ち越しを片付ける**: #190 と H-28・H-29（E-128）
