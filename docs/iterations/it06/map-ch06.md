### 2.4 変えた理由

西の先兵 `pass_vanguard` の撃破で、中央のソルジャー・斧兵・魔道士の一団を出す。東の奥へ入ると、騎兵とソルジャーの一団を出す。既存のロルフ（HP 33・守備 13）と初期敵・ターン増援の能力は変えていない。騎兵は総 5 → 6、総敵数は 18 → 23。魔法とハンマーを持つ名簿で、ボスへの手段を残した。

## 4. 想定する解き方と別の解き方

- 西の道: (6,14) → (6,10) → (7,6) → ボスの手前 (10,3)。先兵の撃破で中央の一団と魔道士に対応し、回復役が前衛から離れないように進む。
- 東の道: (13,14) → (13,10) → (13,6) → (10,3)。東の進入増援と敵騎兵の再移動を受ける。ロルフには魔法かハンマーを使える。
