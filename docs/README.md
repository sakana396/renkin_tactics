## ID 規約

トレーサビリティのため、要素には次の ID を振る。ふしぎ錬金と同じ規約を使う。

| 接頭辞 | 対象 | 例 |
|---|---|---|
| `FR-<区分>-` | 機能要求（区分の一覧は [SRS](02_requirements/srs.md) 3 章。例: BTL 戦闘、UNT ユニット、MAP マップ） | `FR-BTL-01` |
| `NFR-` | 非機能要求 | `NFR-06` |
| `IF-` | 外部インタフェース要求 | `IF-03` |
| `CST-` | 制約 | `CST-02` |
| `QA-` | 品質保証の要求 | `QA-02` |
| `TBD-` | 要求仕様書の未決事項 | `TBD-03` |
| `UC-` | ユースケース | `UC-02` |
| `DES-` | 設計要素 | `DES-BTL-01` |
| `TC-` | テストケース | `TC-FR-BTL-01-01` |
| `ADR-` | 設計判断記録 | `ADR-0001` |
| `E-` | 要求抽出記録の発言 | `E-04` |
| `Q-` | 企画書の未決事項 | `Q-01` |
| `REV-` | レビュー記録 | `REV-001` |
