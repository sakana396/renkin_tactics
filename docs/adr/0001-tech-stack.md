# ADR-0001: 技術選定（Go ＋ Ebitengine）

- 状態: 案
- 日付: 2026-10-20

## 背景

ふしぎ錬金の戦闘の中心の部分を作り込み、あとでふしぎ錬金に戻す（E-01、E-02）。

## 決定

- 言語は Go、ゲームライブラリは Ebitengine を使う（E-02）
- ふしぎ錬金と同じく、ゲームの規則（core）は Ebitengine に依存させず、画面（ui）と分ける

## 理由

- ふしぎ錬金と同じ技術にすると、戦闘のコードを持ち込みやすく、作り込んだ戦闘を戻しやすい
- 開発者は Go の経験がある

## 影響

- ふしぎ錬金の開発のしくみ（CI、tccheck、フック）をそのまま使える
- 戦闘のコードを戻す方法（パッケージを共有するか、コードを写すか）は、別の ADR で決める
