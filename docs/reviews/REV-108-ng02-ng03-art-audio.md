## 独立レビューで確かめたこと（`af2c869`）

- 画像: 名前の解決（キャラ名 → キャラ ID、クラスの表示名 → クラス ID、同名なら ID の昇順）、`..` を含む道筋の拒否、話者の取り出し（実際の物語の段落で、地の文の途中の台詞を拾わない）、配置の関数の値（設計の数値から手で計算した値と一致）
- 写しに試し用の絵を置いて `-game alchemy` を起動し、タイトル・物語・戦闘・情報欄を撮った。背景と暗い膜、話者の肖像と右へ寄せた本文、盤面のユニットの絵（HP の棒・印・ボスの金の枠は今のまま）、情報欄の肖像と敵のクラスの絵が出た。**撮った画像を機械で読み取っただけで、人が実機の画面を見たわけではない**
- 音: デバイスのない環境で起動し、stderr に 1 回だけ出して無音で続く。出来事 → 効果音、場面 → BGM の対応表は、設計メモ・実装・テストで一致した。`go test -race` は成功
- 合成の音（**数値だけ。耳では聞いていない**）: 16 bit・モノ・22050 Hz、クリップ 0、BGM は 20.000 秒で継ぎ目は滑らか、合計 4.04 MB。コミットした WAV は `tools/synth` の出力とバイト単位で一致した
- 既存の作品: Media が nil なら画像を読まず、音も組み立てない。`defs.Catalog` は追加だけ。Windows 向けのビルドは cgo なしで成功
