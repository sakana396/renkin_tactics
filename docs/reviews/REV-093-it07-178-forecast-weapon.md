## 検証（レビュー時）

- 状態遷移を DES-IT07 3.1・3.7 節（DES-UI-34）と照合した。攻撃では `WeaponMenu` を経ずに 相手 → 予測 へ進む。敵の直接クリックも予測へ進む。仮の武器は、届く装備の武器、なければ手持ち順で最初に届く武器になり、UI だけが持つ。送りは ◀▶・右欄の上のホイール・A・D で循環し、届く武器が 1 本なら送らない。決定は相手の再クリックか「決定」のボタン。失敗したときは状態・仮の武器・装備・履歴を保つ。取消しは、通常の攻撃が 予測 → 相手 → 行動の一覧 → 移動先の選択、直接クリックが 予測 → Selected。杖・再移動・巻き戻しの入口は変えていない
- 予測の見た目は右欄のまま、末尾に武器送りの 1 行を置いた（#166 の範囲は作っていない）
- gofmt・go vet（ui・cmd を除く）・GOOS=windows go vet・go test（ui・cmd を除く）・tccheck（警告 85 件）は成功。ui は Linux でビルドできない。CI（run 41648532110）は TC-FR-MAP-06-07 と TC-IF-02-02 の 2 件が失敗した
- UI のテストをこの環境で動かせないため、ミュータントで落ちるかはコードを読んで判断した
