- TC-FR-BTL-10-24・25・26 の ID は、仕様書・コード・traceability でそろっている。変えた行の列数・閉じの区切り・表の中の空行を確かめた（REV-031、REV-033、REV-042）
- 7.1 節の配置のとおり、右欄（x=512〜832）の一覧・確認と、下の案内（y=512〜576）で盤面を覆わない。一覧 y=60〜284、ページ y=292〜320、詳細 y=328〜428、回数と理由 y=436〜496、ボタン y=520〜560

- 期待値は 4.1・4.2・7.1 節と basicSetup の既知の入力（移動前のガルドは (0, 2)、2T 自軍の行の盤面は 1T 敵軍）から導ける。確定後の盤面は、見ていたプレビューと一致する
- プレビューのユニットは drawUnitList（unitTile）で描く。TC-FR-UNT-09-18 のプレビューの場面で、騎兵の 3 体が騎乗の絵になる（REV-045 F-03 の申し送り）
