- 計測器の最小費用の探索は、`reachableWithin`・`zocCost` と同じ規則である（入るマスだけ +1、ZOC は最大 +1、相手軍の生存重騎士のみ、相手のマスは通れず味方のマスは通れる、移動者は除く）。同じ費用の経路での下限・上限の合わせ方も正しい。Event.Units は出来事の直後の写しで、移動者を出発点に戻して移動前の盤面を作っている。地形は戦闘中に変わらない。
