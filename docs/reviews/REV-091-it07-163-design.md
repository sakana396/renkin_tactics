## 検証

- 新しい設計 ID は既存の末尾 DES-UI-28、DES-AI-02、DES-BTL-10、DES-DAT-04、DES-MAP-08 から続く DES-UI-29〜35、DES-AI-03、DES-BTL-11、DES-DAT-05、DES-MAP-09 である
- `game.go`、`input.go`、`rewind.go`、`minimap.go`、`hint.go`、`camera.go`、`data/base/maps.toml` と定義・キー・座標・データの形を照合した。`game.go` で A・D は未使用。Q は Playing・Over 以外と配置で受ける
- 5.5 節の初期敵数と小隊長数を `data/base/maps.toml` から数え直した。ch01〜09 は順に 8+1、8+1、10+1、12+2、9+1、14+2、10+1、16+2、26+3 で、最大は ch09 の 29 体。出来事の一団 15 にも各 1 体を足す案と照合した
- 4.2 節の平地の例は進入先 `Cost+Z` で検算し、4.3 節の Mov 7、移動費 3、残り 4 を検算した。逆向き探索の辺は敵が入る側の費用と明記した
- 8 章の依存は IT07-PLAN 7 章の A、1〜10、最後の順と一致する。設計書の未承認という状態を保った
- `gofmt -l .` は出力なし。`GOOS=windows go vet ./...` は指摘なし。`go test ./...` は core・tactics・defload ほかが ok、ui・cmd は Linux に X11/Xlib.h がなくビルドに失敗した。`go run ./tools/tccheck` は OK（既存の警告 48 件）
